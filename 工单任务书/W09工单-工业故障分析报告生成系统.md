### 知识四要素详解（V1.2深度版·与授课PPT同源）

**B01 pip与离线whl**
- 定义：pip=应用商店；whl=下载好的安装包——断网也能装
- 使用场景：机房无外网时用whl装jieba/wordcloud
- 应用实例：pip install jieba-0.42.1-py3-none-any.whl
- 扩展与误区：误区：没激活环境就装——装到base等于白装，先conda activate
- 原理：pip是包管理器：在线pip install jieba、离线pip install xxx.whl——内网机器先外网下载whl再U盘拷入安装
- 判断依据：机房无外网时：外网pip download jieba -d ./whls 下载全依赖→拷贝→离线pip install --no-index --find-links=./whls jieba
- 逐行解释：pip install D:/whls/jieba-0.42.1-py3-none-any.whl 直接装本地文件；pip list 查看已装版本——离线三步：下载/拷贝/安装
- 进阶优化：requirements.txt锁定版本(pip freeze>)供他机一键复现；国内镜像-i https://pypi.tuna.tsinghua.edu.cn/simple提速

**B02 jieba分词**
- 定义：jieba=中文切词刀：英文按空格切，中文得靠它切词
- 使用场景：'泵体振动异常'→['泵体','振动','异常']——文本分析第一步
- 应用实例：words = list(jieba.cut(text))
- 扩展与误区：误区：cut_all=True切太碎——教学与统计默认精确模式
- 原理：jieba基于前缀词典+动态规划找最大概率路径分词，未登录词用HMM模型补刀——中文没有空格，分词是文本处理第一步
- 判断依据：故障报修单、运维日志这类中文文本，先jieba.cut切词再统计——'轴承磨损'要切成'轴承/磨损'两个词
- 逐行解释：words=jieba.lcut('3号泵轴承异响') →['3','号','泵','轴承','异响']；lcut直接返列表，cut返生成器——名单落袋才能数频次
- 进阶优化：jieba.add_word('伺服电机')把专业词加入词典防切散；load_userdict('mydict.txt')整份行业词典一次导入

**B03 停用词过滤**
- 定义：停用词=搭头话：'的/了/在'没信息量，先请出场
- 使用场景：虚词霸榜时词频统计没意义——先过滤再计数
- 应用实例：words = [w for w in words if w not in stopwords]
- 扩展与误区：误区：词频不看停用词→Top10全是'的了我们'——白统计
- 原理：停用词是'的/了/在'这类高频无义虚词——不过滤会霸榜词频，把'轴承'挤到十名开外
- 判断依据：统计词频前先过滤停用词+单字+标点——榜单才能反映真实故障焦点
- 逐行解释：STOP={'的','了','在','是'} 自建小表；filtered=[w for w in words if w not in STOP and len(w)>1] 列表推导一行完成双滤
- 进阶优化：哈工大停用词表(百度可下)覆盖更全；进阶按业务补充'正常/运行'这类'业务停用词'

**B04 Counter词频**
- 定义：Counter=计票员：过一遍全记下，most_common(n)念前n名
- 使用场景：故障报告高频词排行——维修重点的风向标
- 应用实例：Counter(words).most_common(10)
- 扩展与误区：误区：手写dict计数30行——Counter一行搞定，字典子类白送
- 原理：Counter是计数字典的强化版：most_common(n)直接给TopN——词频统计三行代码的事
- 判断依据：凡'数出现次数/取前几名'的场景：词频、告警类型分布、设备故障排行——Counter包办
- 逐行解释：cnt=Counter(filtered) 一行数完；cnt.most_common(10) Top10榜单[(词,次数),...]——for w,c in ... 直接遍历打榜
- 进阶优化：Counter间可加减（两月词频做差看新增话题）；update()增量累计；matplotlib画横向条形图即词云数据底座

**B05 TF-IDF关键词**
- 定义：TF-IDF=本篇常讲+别人少讲=这篇的关键词——稀有度加权
- 使用场景：'气蚀'比'设备'更能代表这篇报告——专属词升权
- 应用实例：TfidfVectorizer().fit_transform(docs)——sklearn一行
- 扩展与误区：误区：TF-IDF值不是词频——是权重分，值越大越具代表性
- 原理：TF-IDF给词打'含金量'：出现多的词(TF)乘以'只在少数文档出现'(IDF)——'设备'哪都有不值钱，'气孔'独此一份是金词
- 判断依据：词频看热度、TF-IDF看辨识度：从几百条报修里提炼'关键词'上榜，TF-IDF比裸词频更准
- 逐行解释：from jieba.analyse import extract_tags; extract_tags(text,topK=5) 一行出前5关键词——内部就是TF-IDF打分排序
- 进阶优化：withWeight=True同时返回权重值；进阶用sklearn的TfidfVectorizer做全文档矩阵（下学期机器学习课主修）

**B06 wordcloud中文字体**
- 定义：wordcloud不认中文字体=画一页方框——font_path指定字体
- 使用场景：词云是故障报告的可视化封面——领导先看图后看数
- 应用实例：wc = WordCloud(font_path='ZH_Font.ttf')
- 扩展与误区：误区：路径错不报错只方框——先单独generate再to_file排查
- 原理：wordcloud默认字体不含中文——必须font_path指定中文字体文件，否则词云全是口口方块
- 判断依据：画中文词云报'豆腐块'时：wc=WordCloud(font_path='simhei.ttf') 指定黑体/微软雅黑路径即刻修复
- 逐行解释：WordCloud(font_path='C:/Windows/Fonts/simhei.ttf',background_color='white').generate(' '.join(words)) 空格拼接是关键；.to_file('w9.png')落盘
- 进阶优化：width/height调分辨率、collocations=False去重复合词、mask参数套自定义形状（如泵轮廓）——报告封面级效果
