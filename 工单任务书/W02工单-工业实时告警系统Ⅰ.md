### 知识四要素详解（V1.2深度版·与授课PPT同源）

**B01 if/elif/else分支**
- 定义：程序岔路口：if问一句'满不满足'，满足走这条路
- 使用场景：温度超限告警/振动分级——车间判断全走岔路口
- 应用实例：if temp>=80: print('报警') else: print('正常')
- 扩展与误区：误区：缩进漏4空格→IndentationError——缩进即语法不是美观
- 原理：if/elif/else自上而下短路执行：命中一个分支立即跳出，剩余条件不再看——顺序就是优先级
- 判断依据：多级告警必须'先判危险再判警告'：95℃停机条件放最前，写反了80℃先命中、危险被吞
- 逐行解释：if temp>=95: 停机 —— 第一道筛最危险；elif temp>=80: 警告 —— 前面不中才轮到它；else: 正常 —— 兜底
- 进阶优化：条件超过4层改用字典映射级别号；match-case(Python 3.10+)结构化分支更清晰

**B02 比较与赋值**
- 定义：=是'装进去'，==是'比一比'——一横之差意思全变
- 使用场景：告警判断写错=误操作——if temp=80直接语法错误
- 应用实例：if temp == 80: print('到限')
- 扩展与误区：误区：=写进if→SyntaxError；比较浮点用差值<1e-6不用==
- 原理：==是比较运算符算出True/False，=是赋值语句不返回值——把==写成=在条件里直接SyntaxError，这是安全的 typo
- 判断依据：判断字段相等用==；给变量存值用=；if里出现单=是硬错误，编译器帮你拦住
- 逐行解释：temp==80 问'等于吗'→False；temp=80 是'存80'→无返回值；>=80 是≥含等号（80本身触发）——边界归属想清楚再选符号
- 进阶优化：连续比较80<=temp<95数学写法Python原生支持；is只用于None判断，值比较永远用==

**B03 逻辑运算and/or/not**
- 定义：and同真才真/or一真即真/not翻面——复杂条件加括号
- 使用场景：温度高且振动大才停机——多条件联锁判断
- 应用实例：if (temp>=80) and (vib>4.5): 停机
- 扩展与误区：误区：优先级记不清就全加括号——and比or优先，加括号最稳
- 原理：and全真才真、or一真即真、not取反——组合条件按'短路求值'：and左假即停、or左真即停，省掉无谓计算
- 判断依据：温度且振动同超才升级（and防误报）；温度或电流任一超即查（or防漏报）；not反转'设备不在维护态'这类否定条件
- 逐行解释：(temp>=80) and (vib>4.5) 两个括号显式分组免歧义；not device.in_maint 在维护中则不告警
- 进阶优化：短路特性可当保护用：if door_closed and start_press(): 门没关就不按启动；多重条件抽成具名函数is_danger(t,v)可读性翻倍

**B04 嵌套判断**
- 定义：if里套if=先粗筛再细筛——像分拣机先挑大类再细分
- 使用场景：先筛高危设备再定位具体泵——排查有先后
- 应用实例：if level=='alarm': 里层 if device=='PUMP-03'
- 扩展与误区：误区：嵌套超2层读不动——再深就抽函数（下节课）
- 原理：嵌套判断是'先粗筛再细查'两层漏斗：外层定大类、内层定小类，缩进层级=决策深度
- 判断依据：先分设备类型再分阈值档（不同设备阈值不同）时用嵌套；层级≤2为宜，3层以上说明该拆函数
- 逐行解释：if dev=='PUMP': 外层筛泵类；if temp>=80: 内层泵专属阈值 —— 换成VFD则走另一套内层——同类同阈值、异类各自一套
- 进阶优化：深嵌套拍平技巧：早返回(guard clause)——不满足直接return；或用字典存每类设备的阈值配置

**B05 边界值三测法**
- 定义：边界三测：限值前/限值上/限值后各测一遍
- 使用场景：阈值80到底>=还是>——79.9/80/80.1三发子弹裁决
- 应用实例：80报不报？>=80报 → 与'≥80报警'工艺单一致
- 扩展与误区：误区：只测中间值——工业验收规定边界必测，>=和>差一台停机
- 原理：计算机比较浮点有精度陷阱：79.99999≠80——边界值三测法用'贴线两侧+恰在线上'三个点验证分支归属
- 判断依据：每写一个阈值判断必测三组：79.9(线下)/80.0(线上)/80.1(线上)——确认80归警告而非正常
- 逐行解释：边界表逐行打勾：temp=79.9→正常、80.0→警告(含等号)、95.0→停机(含等号)——表格即测试用例
- 进阶优化：进阶把边界表写成pytest参数化用例自动回归；浮点比较用math.isclose(a,b)替代==防精度坑

**B06 告警三级分级**
- 定义：提示=记本子/警告=喊人/停机=自动断——轻重分级
- 使用场景：车间告警不能一刀切——分级响应才能不漏不大惊小怪
- 应用实例：>=90停机 / >=80警告 / >=70提示（elif顺序）
- 扩展与误区：误区：elif从严到窄写——先写>=70会把90也截走，顺序即逻辑
- 原理：告警三级分级是工业惯例：提示(记录观察)→警告(加密监测)→停机(通知班长)——级别对应响应动作，不是文字游戏
- 判断依据：阈值+响应动作成对设计：70℃提示/80℃警告/95℃停机；响应里写清'谁在多久内做什么'
- 逐行解释：level=3 if temp>=95 else (2 if temp>=80 else 1) 三元链算级别号；alarm(level,msg)按级别打不同前缀——[停机]红色意义即动作
- 进阶优化：级别映射用字典{95:3,80:2,70:1}+循环判档；生产系统告警还带迟滞(hysteresis)：回落2℃才解除防反复横跳

## 避坑
- `=` 与 `==` 混用；
- elif 顺序错误（先判>80再判>95 → 永远到不了95分支）；
- and/or 优先级：`a>80 and b>0.8 or c` 加括号最稳。
