### 知识四要素详解（V1.2深度版·与授课PPT同源）

**B01 for与while**
- 定义：for=点名册逐个念；while=哨兵盯着条件转圈
- 使用场景：10台设备逐台采集用for；持续监控用while
- 应用实例：for i in range(10): 读第i台；while running: 采集
- 扩展与误区：误区：range(1,10)不含10——左闭右开'含头不含尾'，数轴画一遍
- 原理：for遍历'有限序列'（列表/字符串/range），while盯住'变化条件'——两者都能循环，选型看'次数已知'还是'条件满足'
- 判断依据：已知循环10个周期用for range(10)；温度不回落就一直监测用while temp>=80——次数未知条件已知
- 逐行解释：for cycle in range(10): 逐周期判读；while temp>80: 循环体里必须更新temp否则死循环——while三件套缺一不可
- 进阶优化：for+enumerate同时拿下标与元素；while配sleep(1)做轮询监测，退出条件写日志留痕

**B02 break与continue**
- 定义：break=拉闸走人；continue=跳过这个下一个
- 使用场景：坏数据跳过本轮继续采；用户按停跳出全部
- 应用实例：if data is None: continue；if stop: break
- 扩展与误区：误区：break只跳一层——双层循环里内层break管不住外层
- 原理：break整层立即跳出（紧急止损），continue只跳过本轮进下一轮（跳过无效样本）——一个弃车保帅一个绕障前行
- 判断依据：读到设备离线记录直接break终止采集；某条数据缺失/非法用continue跳过继续处理后面
- 逐行解释：for r in rows: if r.offline: break 遇离线即停；if r.temp is None: continue 空温度跳过——后面print照常跑下一轮
- 进阶优化：for...else语法：循环没被break才执行else——'全部处理完'分支的优雅写法；深嵌套里break只跳一层，跨层用标志位

**B03 循环三要素**
- 定义：初始值/继续条件/每轮更新——缺一个就转成死循环
- 使用场景：while手写循环的自检口诀——写前先默念三件套
- 应用实例：i=0 → while i<10 → i+=1
- 扩展与误区：误区：忘i+=1死循环——急救Ctrl+C；写while先想'怎么退出来'
- 原理：循环三要素=初始化+条件+更新：缺初始化NameError、缺条件永真死循环、缺更新条件永不变化——三者闭环才健康
- 判断依据：写循环前先口述三要素：i从几开始(初始化)、到几停(条件)、怎么走(更新)——说不清就别动手
- 逐行解释：i=0 初始化；while i<10 条件；循环体末尾i+=1 更新——漏掉最后这行CPU原地打转，Ctrl+C才能救
- 进阶优化：死循环排查：看条件里的变量在体内有没有被更新；for天然自带三要素，能for尽量不用while

**B04 random随机数**
- 定义：random.uniform(a,b)=在[a,b]扔骰子；seed=固定骰子
- 使用场景：模拟传感器读数——没有真设备时的替身演员
- 应用实例：random.seed(42)后每次运行数据一样——可复现
- 扩展与误区：误区：不设seed每次结果不同没法调试——仿真加seed是工程惯例
- 原理：random是伪随机：同一seed下序列完全可复现——seed(42)固定后，每次跑出的'随机'数据一模一样
- 判断依据：模拟传感器数据做测试用random；交作业/复现bug时先seed固定——'随机'结果可复现才可调试
- 逐行解释：random.seed(42) 播种；random.uniform(70,90) 生成区间内浮点温度——两行造出10个周期模拟数据
- 进阶优化：random.choice从设备列表随机点名、random.gauss正态分布更贴近真实传感噪声；安全相关随机用secrets模块

**B05 函数封装**
- 定义：def=给一段逻辑起名装盒：投料(参数)出产品(返回值)
- 使用场景：告警判断/换算抽成函数——写一次处处用
- 应用实例：def c2f(c): return c*9/5+32 → c2f(78.5)
- 扩展与误区：误区：忘return打印None——return是交货print是喊话，两码事
- 原理：函数=打包复用的最小单元：参数是入口、return是出口、函数体是黑盒——定义一次到处调用，改一处全局生效
- 判断依据：同一段逻辑出现第二次就该抽函数；check_device(dev)比复制粘贴十遍强在'改阈值只改一处'
- 逐行解释：def check_device(dev): 定义签名；体内判阈值；return alarm_count 出口返回统计——调用方total=check_device(d1)接住返回值
- 进阶优化：单函数≤15行是本课军规；参数带默认值def read(path, mode='r')调用即简化；进阶类型注解def f(x:float)->str

**B06 列表与字典入门**
- 定义：列表=排队货架(有序可重复)；字典=储物柜(编号取物)
- 使用场景：设备清单用列表；'编号→温度'台账用字典
- 应用实例：devs.append('MOTOR-01')；t={'PUMP-03':78.5}
- 扩展与误区：误区：t['PUMP4']查无此键KeyError——先用 in 判断再取
- 原理：列表是有序可变集合（按下标存取），字典是键值映射（按名字存取）——'一排数据'用列表，'一物一档'用字典
- 判断依据：3台设备排队巡检用列表[dev1,dev2,dev3]；每台设备的编号/温度/状态建档用字典{'id':'P3','temp':78.5}
- 逐行解释：devices[0]取第一台；d['temp']按键取值——键必须是不可变类型(str/int)；d.get('temp',0)键不存在给默认值不报错
- 进阶优化：字典推导式{d['id']:d for d in devices}一键建索引表；进阶collections.OrderedDict/defaultdict治计数场景
