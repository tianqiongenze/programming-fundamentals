## 虚拟产线使用（第11周）

```bash
# 终端1: 启动Modbus模拟器(3台PLC, 端口5020/5021/5022)
python 虚拟产线/mini_modbus_server.py 5020 1 &
python 虚拟产线/mini_modbus_server.py 5021 2 &
python 虚拟产线/mini_modbus_server.py 5022 3 &
# 终端2: 启动MQTT代理(端口1883)
python 虚拟产线/mini_mqtt_broker.py &
# 终端3: 学生程序连接 127.0.0.1 即可(无需外网/Docker)
```

## 使用流程

1. **课前**：发布当周工单+starter；W1-6学生完成"模仿预习"（跟打示例代码），W7-12完成导学单（资讯·计划）。
2. **课中**：W1-6 按"讲15→演15→模仿→练习"；W7-12 按"决策→两轮实施→三层检查→评价"。
3. **课后24h**：D/C/B/A评分反馈；困难学生进补强名单（学习伙伴结对）。
4. **第6周中期诊断 / 第11周末期复习+项目启动 / 第12周答辩专场**（v2.0关键调整）。
