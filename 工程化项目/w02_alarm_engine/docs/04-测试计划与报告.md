# 04 测试计划与报告（GB/T 15532《计算机软件测试规范》）

> 项目：设备多级告警判定引擎（工单 W02《工业实时告警系统Ⅰ》）

## 1. 测试策略
| 层级 | 方法 | 目标 |
|---|---|---|
| 单元测试 | pytest，`core` 判级/去重纯函数 | 覆盖正常/边界/异常三档 |
| 集成测试 | pipeline 端到端（临时目录） | 读数流→告警流→统计链路正确 |
| **验收测试** | `tests/test_acceptance.py` 逐档断言 | 工单 D/C/B/A 四档可量化复现 |
| **规范率实测** | `stylecheck.py`（pycodestyle 2.14，缺失时降级内置体检器） | 每档"规范率≥N%"有真实数字 |
| 回归 | `pytest -q` 全量 | 任一改动不破坏既有行为 |

## 4. 缺陷记录
| 编号 | 描述 | 处置 |
|---|---|---|
| D-01 | 原 `alarm(msg, level=...)` 形参顺序与工单签名不符 | 改为 `alarm(level, msg)`，测试用 `inspect.signature` 锁死 |
| D-02 | 边界用例只到 79.9/100（温度）而压力缺 0.8MPa 硬上限 | 补齐温度 5 组 + 压力 5 组（含 0.8） |
| D-03 | 无多条件嵌套分支（B 档），三台设备循环缺失（A 档） | 新增 `nested_level()` 真嵌套 + `sweep()` 三台循环 |
| D-04 | 无规范率量化手段 | 引入 `stylecheck.py` + `[tool.pycodestyle]` 双侧断言 |
| D-05 | E127 续行多缩进 1 处（pipeline 输入口径） | 拆为局部 `scope` 字符串，实测归零 |
