# 07 架构决策记录 ADR-001：规则阈值用 YAML 外置而非代码常量

- 状态：已接受
- 日期：2026-10-14
- 决策者：项目组

## 背景
产线阈值随工艺调整频繁；写死在代码里每次都要改代码、走发布流程，且容易漏改

## 备选方案
A 代码常量（快但难维护）｜B YAML 外置（改配置即生效）｜C 数据库规则表（需额外依赖）

## 决策
**采用：B YAML 外置**

## 理由
改配置不改代码是 GB/T 8566 配置管理过程的基本要求；yaml_lite 保证零依赖可跑

## 后果
- 正面：配置文件错误要到运行期才暴露
- 负面/代价：中
- 缓解：启动时校验阈值顺序，非法即拒绝
