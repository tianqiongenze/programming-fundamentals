# 07 架构决策记录 ADR-001：巡检矩阵用 dict-of-list 而非二维 list

- 状态：已接受
- 日期：2026-10-14
- 决策者：项目组

## 背景
设备数/周期数会变；二维 list 扩容和索引可读性都差，且无法按设备名直接寻址

## 备选方案
A 二维list（紧凑但难读）｜B dict[str, list]（按名字寻址）｜C pandas（引入重依赖）

## 决策
**采用：B dict[str, list]**

## 理由
按设备编号寻址可读性好；纯标准库；周3循环语法刚好练习嵌套 for

## 后果
- 正面：内存略高于稀疏结构
- 负面/代价：低
- 缓解：数据量大时再迁 pandas
