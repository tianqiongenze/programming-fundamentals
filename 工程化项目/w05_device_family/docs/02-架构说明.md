# 02 架构说明（TOGAF 四域视角）

> 项目：设备继承体系

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 一接口管多种设备，调度层无需为每种设备写分支代码 |
| 数据架构 | Device 基类定义共同状态；子类扩展专属字段（freq_hz / delay_s）；fleet 为异构设备清单 |
| 应用架构 | core 定义类层次 + 工厂函数 from_dict()；pipeline 统一遍历 fleet 调用统一接口 |
| 技术架构 | Python 3.12 + conda py02；仅标准库（abc 抽象基类）；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | Device 基类 + Pump/Fan 子类 + 工厂 | `Device.dispatch()/from_fleet()` |
| `pipeline.py` | 异构设备统一调度 | `run(cfg, out_dir)` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
