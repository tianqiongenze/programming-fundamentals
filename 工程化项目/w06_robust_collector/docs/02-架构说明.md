# 02 架构说明（TOGAF 四域视角）

> 项目：健壮工业数据采集

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 脏数据不再让采集中途崩溃；异常可追溯、可回放，保住过程性证据 |
| 数据架构 | 原始行（字符串）→ 校验后记录（temp/press）+ 坏数据隔离区（行号+原文+原因） |
| 应用架构 | core 单行解析与校验（纯函数）；pipeline 逐行消费、隔离与统计 |
| 技术架构 | Python 3.12 + conda py02；仅标准库（logging）；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 单行解析/单字段校验/行级隔离 | `parse_line()/validate()` |
| `pipeline.py` | 逐行采集→隔离→统计 | `run(cfg, out_dir)` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
