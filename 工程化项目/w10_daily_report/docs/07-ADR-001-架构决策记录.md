# 07 架构决策记录 ADR-001：reportlab 缺失时降级为 Markdown 而非直接报错

- 状态：已接受
- 日期：2026-10-14
- 决策者：项目组

## 背景
机房未必预装 reportlab；日报任务是主目标，PDF 只是展示格式，不应因缺库而失败

## 备选方案
A 强制依赖报错（简单但脆）｜B 探测后降级（健壮）｜C 用纯文本假装是PDF（误导）

## 决策
**采用：B 探测后降级**

## 理由
主流程（算指标/出报表）永不被阻塞；README 明确说明降级行为与安装命令

## 后果
- 正面：降级产物非 PDF
- 负面/代价：低
- 缓解：README 标注：需要 PDF 请装 reportlab
