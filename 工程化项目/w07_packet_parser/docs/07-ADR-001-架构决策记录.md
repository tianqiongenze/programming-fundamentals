# 07 架构决策记录 ADR-001：报文解析器用路由表（策略模式）而非 if-else 链

- 状态：已接受
- 日期：2026-10-14
- 决策者：项目组

## 背景
设备品牌只会增加；if-else 链每次新增都要改同一函数，违反开闭原则

## 备选方案
A if-else 链（前几种够用）｜B PARSERS 路由表（注册即可扩展）｜C 正则表达式大全（难读难维护）

## 决策
**采用：B PARSERS 路由表**

## 理由
新格式=新函数+一行注册；每种格式可独立单测；路由顺序即优先级

## 后果
- 正面：数量极多时需做前缀索引优化
- 负面/代价：低
- 缓解：保持 ≤6 种格式，超出再上索引
