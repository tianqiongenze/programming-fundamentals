# 07 架构决策记录 ADR-001：设备用 dataclass(frozen=True) 而非 dict

- 状态：已接受
- 日期：2026-10-14
- 决策者：项目组

## 背景
设备参数要被多处只读使用；用 dict 时拼写错误不会报错（静默 bug），且无法表达不可变语义

## 备选方案
A dict（灵活但无约束）｜B dataclass(frozen=True)（有类型+不可变）｜C Pydantic（重，课堂不必要）

## 决策
**采用：B dataclass(frozen=True)**

## 理由
类型提示让 IDE 可补全；frozen 让误修改变得显式报错；零第三方依赖

## 后果
- 正面：字段增删需改类定义
- 负面/代价：低（周1即可理解）
- 缓解：在 README 说明用法
