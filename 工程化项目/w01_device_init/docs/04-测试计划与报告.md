# 04 测试计划与报告（GB/T 15532《计算机软件测试规范》）

> 项目：设备参数初始化系统（工单 W01《设备参数初始化系统》）

## 1. 测试策略
| 层级 | 方法 | 目标 |
|---|---|---|
| 单元测试 | pytest，`core` 换算/判级/校验纯函数 | 覆盖正常/边界/异常三档 |
| 集成测试 | pipeline 端到端（临时目录） | 输入→输出链路正确 |
| **验收测试** | `tests/test_acceptance.py` 逐档断言 | 工单 D/C/B/A 四档可量化复现 |
| **规范率实测** | `stylecheck.py`（pycodestyle 2.14，缺失时降级内置体检器） | 每档"规范率≥N%"有真实数字 |
| 回归 | `pytest -q` 全量 | 任一改动不破坏既有行为 |

## 4. 缺陷记录
| 编号 | 描述 | 处置 |
|---|---|---|
| D-01 | 工单要求"f-string 设备台账卡"，原实现只有零散 `print`，无整卡输出 | 新增 `core.card()`，全 f-string 排版（TC-03） |
| D-02 | 变量仅 6 个 / 3 类，达不到 B 档 ≥8 变量 4 种类型 | 台账扩到 10 字段 4 类型（电压/功率/投产年份/运行位） |
| D-03 | 无 A 档 `input()` 变体 | 新增 `interactive_card(cfg, reader=)`，可注入读取器供测试 |
| D-04 | 无规范率量化手段，工单"≥70/75/90%"无法验收 | 引入 `stylecheck.py` + `[tool.pycodestyle]`，报告与测试双侧断言 |
| D-05 | E128/E741 等 6 处 PEP 8 违规 | 提出局部变量、消除歧义短名，实测归零 |

> 本轮无遗留缺陷。
