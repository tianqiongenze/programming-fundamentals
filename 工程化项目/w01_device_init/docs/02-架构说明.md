# 02 架构说明（TOGAF 四域视角）

> 项目：设备参数初始化系统

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 设备铭牌参数集中管理，消除 Excel 抄录错漏，为巡检与告警提供唯一数据源 |
| 数据架构 | 设备清单为值对象（code/name/temp/press_kpa/rpm/status），设备编号唯一；原始清单存 config/devices.yaml，输出为 JSON 台账 |
| 应用架构 | core 负责单位换算与告警分级；pipeline 负责加载设备→生成台账→评估→报告 |
| 技术架构 | Python 3.12 + conda py02；仅标准库；pytest 断言；CLI 入口 run.py |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `config.py` | 加载 YAML 设备清单与阈值 | `load_config()` |
| `core.py` | 单位换算/告警分级/台账卡格式化 | `c_to_f()/kpa_to_mpa()/level_of()/card()` |
| `pipeline.py` | 加载→换算→评估→报告 | `run(cfg, out_dir)` |
| `io_utils.py` | JSON 原子写 | `write_json()/write_text()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
