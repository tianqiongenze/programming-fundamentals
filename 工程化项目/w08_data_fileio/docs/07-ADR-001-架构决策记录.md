# 07 架构决策记录 ADR-001：数据落盘同时输出 CSV 与 JSON 两份

- 状态：已接受
- 日期：2026-10-14
- 决策者：项目组

## 背景
下游工具取数格式不一（Excel 用 CSV、程序用 JSON）；只输出一种会逼某一方做转换，易出错

## 备选方案
A 只出 CSV（Excel友好但程序要手写解析）｜B 只出 JSON（程序友好但业务看不了）｜C 两份都出（单一数据源派生）

## 决策
**采用：C 两份都出**

## 理由
同一份内存数据派生两种格式，成本极低；CSV/JSON 各有明确消费方

## 后果
- 正面：两份文件需保证同步
- 负面/代价：低
- 缓解：校验逻辑保证两份内容一致
