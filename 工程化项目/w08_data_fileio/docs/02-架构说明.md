# 02 架构说明（TOGAF 四域视角）

> 项目：工业数据文件处理

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 检测数据可持久化、可回溯，支撑质量追溯与二次分析 |
| 数据架构 | 行数据（code/temp/press）→ CSV 与 JSON 双格式落盘；读回后做一致性校验 |
| 应用架构 | core 做聚合统计与一致性校验；io_utils 提供原子写/CSV/JSON；pipeline 编排 |
| 技术架构 | Python 3.12 + conda py02；仅标准库（csv/json/tempfile）；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 聚合统计 + 读写一致性校验 | `summarize()/verify_roundtrip()` |
| `io_utils.py` | CSV/JSON 原子读写 | `read_csv_rows()/write_csv_rows()/write_json()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
