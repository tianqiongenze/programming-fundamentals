# 07 架构决策记录 ADR-001：中文分词用二元词兜底而非 jieba

- 状态：已接受
- 日期：2026-10-14
- 决策者：项目组

## 背景
机房租算机无法安装 jieba；二元词方案零依赖即可跑通，且能让学员看到'分词的起点'

## 备选方案
A jieba（准但需安装）｜B 二元词（零依赖，教学够用）｜C ultralytics级别的模型（过度）

## 决策
**采用：B 二元词**

## 理由
零第三方依赖；课堂任意机器可复现；为后续学 jieba/向量检索打基础

## 后果
- 正面：词边界不如专业分词准
- 负面/代价：中
- 缓解：README 标注：生产环境建议换 jieba/LLM 分词
