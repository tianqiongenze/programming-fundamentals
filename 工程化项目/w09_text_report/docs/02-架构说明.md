# 02 架构说明（TOGAF 四域视角）

> 项目：故障文本词频报告

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 从自然语言故障单中提取高频故障模式，指导备件与巡检策略 |
| 数据架构 | 故障描述文本 → 中文二元词计数表（Top-N）+ 停用词表 |
| 应用架构 | core 做分词/计数/排序（纯函数）；pipeline 批量处理故障单并出报告 |
| 技术架构 | Python 3.12 + conda py02；仅标准库（re/collections）；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 中文二元词分词 + 停用词 + 词频 | `tokenize()/count()/topn()` |
| `pipeline.py` | 批量故障单 → Top-N 报告 | `run(cfg, out_dir)` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
