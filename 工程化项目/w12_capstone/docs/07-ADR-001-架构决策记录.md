# 07 架构决策记录 ADR-001：综合项目用'多段纯函数流水线'而非一个巨型 main()

- 状态：已接受
- 日期：2026-10-14
- 决策者：项目组

## 背景
综合题最怕写成 300 行 main；无法单测、无法改动、出错难定位

## 备选方案
A 巨型 main（难测难改）｜B 多段纯函数 + 薄编排（可单测可替换）｜C 引入工作流引擎（过度）

## 决策
**采用：B 多段纯函数 + 薄编排**

## 理由
每段可独立单测与替换；编排层只负责串联；出错能定位到具体段

## 后果
- 正面：函数数量增多
- 负面/代价：低
- 缓解：README 给出流水线图与各段职责
