# 02 架构说明（TOGAF 四域视角）

> 项目：综合数据处理与项目交付

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 一门课的综合验收：把 11 周的碎片能力串成可交付的数据产品 |
| 数据架构 | 脏行（name,temp,press）+ 故障文本 → 清洗后数据集 + 告警表 + 词频表 + 日报 |
| 应用架构 | core 提供解析/清洗/分级/词频四类纯函数；pipeline 串联五段流水线 |
| 技术架构 | Python 3.12 + conda py02；仅标准库；pytest；CLI |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 解析/清洗/分级/词频 四类纯函数 | `parse_row()/clean()/level()/keywords()` |
| `pipeline.py` | 五段流水线编排 | `run(cfg, out_dir)` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
