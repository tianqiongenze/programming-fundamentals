# 04 测试计划与报告（GB/T 15532《计算机软件测试规范》）

> 项目：设备对象建模（工单 W04《工业设备类设计》）

## 1. 测试策略
| 层级 | 方法 | 目标 |
|---|---|---|
| 单元测试 | pytest，`core.Device` 状态机与校验 | 覆盖正常/边界/异常三档 |
| 集成测试 | pipeline 端到端（临时目录） | 输入→输出链路正确 |
| **验收测试** | `tests/test_acceptance.py` 逐档断言 | 工单 D/C/B/A 四档可量化复现 |
| **规范率实测** | `stylecheck.py`（pycodestyle 2.14，缺失时降级内置体检器） | 每档"规范率≥N%"有真实数字 |
| 回归 | `pytest -q` 全量 | 任一改动不破坏既有行为 |

## 2. 用例清单（与工单档位对齐）
| 编号 | 测试对象 | 输入 | 期望 | 档位 |
|---|---|---|---|---|
| TC-01 | 启动 | 停止态 | 成功且 `running` 为真 | D |
| TC-02 | 重复启动 | 运行态再 `start()` | 抛 `AlreadyRunningError` 并留日志 | C |
| TC-03 | 停止态停机 | 未运行 `stop()` | 抛 `NotRunningError` | C |
| TC-04 | 停机后再停机 | 运行→停→停 | 抛 `NotRunningError` | C |
| TC-05 | `running` 只读 | 外部赋值 | `AttributeError`（只能走方法改状态） | C |
| TC-06 | 显式 `__init__` | `inspect` 取源码 | `self.code/kind/temp/status` 均在 `__init__` 内赋值 | D |
| TC-07 | 实例数 | `config/rules.yaml` | ≥3 台（B 档要 3 实例） | B |
| TC-08 | 属性/方法数 | `vars(d)` / `dir(d)` | ≥3 属性 + ≥3 公开方法 | B |
| TC-09 | `__str__` | `print(d)` | 含编号与温度，且不含 `0x` 内存地址 | B |
| TC-10 | `get_status()` | 96℃ | 同时回读状态/读数/判级三要素 | B |
| TC-11 | 实例隔离 | 改 `devs[0]` 温度 | 其余实例读数不变；`plant_code` 类属性共享 | B |
| TC-12 | 读数量程 | ±999℃ | 抛 `OutOfRangeError`（也是 `ValueError`） | B |
| TC-13 | stop 协作日志 | `start()` 后 `stop()` | `logs` 增 1 行字符串且返回值即该行 | A |
| TC-14 | 协作日志导出 | 整段报告 | 含"停机（此刻温度 …）"与 3 条"建档出厂" | A |
| TC-15 | 规则无失效 | pipeline 全跑 | "规则失效项"= 无 | C |
| TC-16 | 规范率四档 | `stylecheck.scan_project` | 实测 ≥75/80/90/90% | D/C/B/A |
| TC-17 | 体检非空转 | 文件数/行数 | ≥8 文件、≥200 有效行、能定位 file:line | B |
| TC-18 | 防伪造 | 已提交 `output/report.txt` | 内含当次实测的规范率数值 | B |
